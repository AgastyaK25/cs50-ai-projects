# CS50's Introduction to Artificial Intelligence with Python

A collection of 11 Python projects exploring fundamental artificial intelligence concepts, including search algorithms, logical inference, probabilistic reasoning, machine learning, neural networks, and natural language processing.

Completed as part of [Harvard University's CS50's Introduction to Artificial Intelligence with Python](https://cs50.harvard.edu/ai/).

## Projects

| Project | Description | Key Concepts |
|---|---|---|
| **Degrees** | Finds the shortest connection between actors through shared films. | Breadth-first search, graphs |
| **Tic-Tac-Toe** | Determines optimal moves for an AI opponent in Tic-Tac-Toe. | Minimax, adversarial search |
| **Knights** | Solves logic puzzles by representing and evaluating logical statements. | Propositional logic, inference |
| **Minesweeper** | Uses logical knowledge to identify mines and safe cells. | Knowledge representation, logical inference |
| **PageRank** | Ranks web pages based on the structure of links between them. | Graph algorithms, iterative computation |
| **Heredity** | Estimates the probabilities of genetic traits from family relationships. | Bayesian networks, probability |
| **Crossword** | Generates crossword solutions while satisfying word and grid constraints. | Constraint satisfaction, backtracking |
| **Shopping** | Predicts whether online shopping sessions will result in a purchase. | Machine learning, classification |
| **Nim** | Develops a game-playing AI that learns strategies through experience. | Reinforcement learning |
| **Traffic** | Classifies traffic signs using image data. | Neural networks, image classification |
| **Parser** | Analyzes sentences to identify their grammatical structure. | Natural language processing, context-free grammars |

## Technologies

- **Language:** Python
- **Algorithms:** Graph search, minimax, backtracking, and constraint satisfaction
- **Artificial Intelligence:** Logical inference, Bayesian networks, reinforcement learning, and neural networks
- **Machine Learning:** Classification and predictive modelling
- **Other areas:** Natural language processing and image classification

## Running the Projects

1. Install Python 3 (some project files require pygame support).
2. Clone the repository:

   ```
   git clone https://github.com/AgastyaK25/cs50-ai-projects.git
   cd cs50-ai-projects
   ```

3. Navigate to the project directory you want to run.
4. Follow any project-specific instructions and install its required dependencies.
5. Run the relevant Python script. For example:

   ```
   python degrees/degrees.py
   ```

   The exact command, input requirements, and dependencies vary by project.
